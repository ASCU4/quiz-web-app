# Online Quiz Web Application

This is an online quiz web application built using HTML, CSS, and JavaScript.  
I built this project to clear my concepts of frontend development.

I took help from a YouTube video for the design and layout so that in the future I can build similar projects independently without major help.

## Features
- Score calculation  
- Multiple-choice questions  
- Simple and clean UI  
- Smooth transitions  

## Technologies Used
- HTML  
- CSS  
- JavaScript
